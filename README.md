## For teachers

1. Tap **Grown-ups**, solve the math problem, and enter the week's spelling words.
2. Type a class name if you like (for example "Room 12") and press **Create a classroom code**.
3. Give the children the 4-digit code. They tap **Join my class** in the wizard's room, type the code, and check it's their class.

Each time you press **Save words**, the class gets the new list.
